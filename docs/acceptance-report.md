## 代码实现

1. 前五关以一分钟为目标：45秒波次后出现Boss，必须击败Boss才结束。三难度共用五关，保留分难度解锁、技能、掉落、剧情及各关机制。无尽模式的原有数值和循环规则保留。
2. 机库夜班在普通模式也能直接进入，联机普通房间同样支持。夜班保留240秒；通过番外不推进普通五关解锁；本次普通夜班通关后，标准第二关仍锁定。
3. 重做值班室与可抬起/收起的监控平板，包含三处监控、左右门灯、机器人位置和电量管理。平板抬起才有监控减速效果，并额外耗电；电量耗尽会收起。平板状态和开关走权威引擎及网络快照。
4. 原有十个WAV逐字节保留。新增三个用户提供录音的完整AAC音轨，以M4A直接封装，不剪辑、不转码；均通过完整解码检查。主页和游戏中均可打开六首歌的电台。来源与权利说明见 music-sources.md。
5. 发布签名改为四项环境变量齐备时启用。公开源码不包含私钥；没有私钥也能构建调试包及未签名发布包。工程内保留唯一一份正式签名APK供clone后直接取得。

## 限制与未验证项

- 没有实体手机流畅度、真实手机Wi-Fi、公网异地联机或扬声器试听通过证据。模拟器以no-audio启动；播放器解码/播放状态不等于听音验收。
- 公网异地联机需要已授权、持续在线的服务器与合适的网络/TLS配置，未购买、部署或虚构此条件。
- 本轮没有重新穷举全部难度的十五次普通通关、全套剧情回看、完整双端比分战斗、多指输入和所有旧功能长时间压力测试；已保留实现和自动检查，历史报告不能直接升级为新包通过。
- 旧2.0客户端连接协议3服务端会断开，旧端只显示普通断线，暂不显示专门升级提示；客户端和服务端必须一起升级。
- 六个审查方向均完成，Boss二阶段发现已修复；上面的旧协议提示限制已记录，不影响本次匹配客户端/服务端运行。
