# 晴空小队

[安装 Android 2.1](release/SkySquad-2.1.apk) · [校验值](release/SHA256SUMS.txt) · [构建说明](BUILDING.md)

一个竖屏飞机大战。暴风雨打乱了岛上的航线，小夏和维修机器人豆丁要找回五枚航标，把失控的运输舰带回家。

Android 8.0 及以上可安装。拖动飞机会自动开火，下方按钮释放技能与炸弹。每次进入关卡先播放一段动画，可点按推进、跳过，也能在航线页回看。

| 航线 | 新内容 |
| --- | --- |
| 1 · 海邮港 | 巡逻机、瞄准射击、邮港巡逻艇 |
| 2 · 风车原野 | 侧风、折线快递机、交叉弹幕 |
| 3 · 积雨云海 | 王牌机、雷云预警、环形弹幕 |
| 4 · 星灯工厂 | 开合护盾、工厂守门员、追踪落雷 |
| 5 · 中央运输舰 | 搭载小飞机的运输机、最终运输舰、二阶段组合攻击 |
| 番外 · 机库夜班 | 监控、左右门与灯、机器人巡游；没有惊吓或恐怖画面 |

轻松、标准、挑战共用五条航线，各自保存解锁进度。过关开放下一关，失败重打当前关。另有保留的无尽模式、四技能、五种补给、Boss 二阶段、音乐电台和分难度排行榜。

前五关以约一分钟为目标（45秒波次后出现Boss，击败后结束；操作会影响实际用时）。番外机库夜班在普通模式也能直接进入，保留四分钟。拿起监控平板可以切换三个机位，收起后查看值班室、门和灯。

设置里的开发者模式开放全部航线，生命、技能与资源无限。开发者成绩单独保存，不推进普通闯关进度。联机以房主的开发者设置为准，双方条件一致。

## 一起玩

支持双人合作闯关与比分对战。合作共享战场，靠近倒地队友可以救援；比分对战各玩同种子的战场。敌人、关卡、技能和 Boss 使用单机的同一套规则。

同一 Wi-Fi 或热点下，一台手机点“一起出发 → 在这台手机开房”，另一台输入房主显示的地址与端口，连接后输入六位房间码。两人到齐由房主出发。也可以运行附带的独立服务器，见 [服务端说明](server/README.md)。

可运行 `./gradlew.bat :server:jar` 构建独立服务端，再执行 `java -jar server/build/libs/sky-room-server.jar --port 8888`。

每一关都等双方看完过场才计时。通关后双方确认进入下一关；失败后双方确认重试。战斗开始后，房主也可以从暂停菜单重打当前关，房间和队友都会保留。任何一方切后台都会暂停，队友不能解除对方的后台暂停。掉线会明确结束本局，可以重新连接。

异地联机需要持续在线的公网服务器。客户端支持可配置地址、端口及验证证书和主机名的 TLS；此交付不包含已经上线的公网服务。

## 代码边界

- `shared/core`：纯 Java 战斗、关卡、夜班、输入和脱离引擎的状态快照。
- `shared/net`：显式二进制协议、房间生命周期、权威服务端、异步客户端与接收截止时间。
- `app`：原生 Android 菜单、剧情、绘制、音频、触摸和生命周期适配。
- `server`：复用同一核心和协议的独立服务器。

逻辑世界固定为 480×800，模拟 60 Hz，网络快照 20 Hz，绘制目标 60 Hz。联机只对显示位置插值，碰撞、血量和胜负始终取服务器状态。实体数有上限，暂停停止本地模拟调度，隐藏或销毁画面会移除帧回调。

依赖由 Android 指向共享核心。关卡数值集中在目录与难度参数里，输入、模拟和显示分开；没有为书中术语增加无用接口或框架。审查处理记录见 [重构说明](docs/refactor-review.md)，实测范围见 [验收报告](docs/acceptance-report.md)。

## 构建与验证

Android 构建需要 JDK 21、Android SDK 36，首次构建还需要下载 Gradle 和 Android 插件依赖。设置 `JAVA_HOME`，用 `ANDROID_HOME` 或本机 `local.properties` 指向 SDK。

```powershell
./gradlew.bat :app:assembleDebug
./tools/verify.ps1 -LongNetwork
```

验证脚本运行核心、真实 socket、超时防护、房间推进、Android 适配器、lint 和 TLS 主机名检查。`-LongNetwork` 额外真实等待完整关卡约一分钟；`-NoAndroid` 只验证共享核心和网络，`-Offline` 使用已经下载的依赖。测试证书临时生成，结束后删除。

发布构建通过环境变量提供 `AIRCRAFT_KEYSTORE_PATH`、`AIRCRAFT_STORE_PASSWORD`、`AIRCRAFT_KEY_ALIAS`、`AIRCRAFT_KEY_PASSWORD`，再运行 `./gradlew.bat :app:assembleRelease`。不提供签名变量时仍能构建未签名 release；`assembleDebug` 可直接安装。签名私钥和密码不在工程包中。

仓库的 `release/SkySquad-2.1.apk` 是这份源码对应的正式签名成品，clone 后即可安装，校验值见 `release/SHA256SUMS.txt`。它是唯一有意保留的构建成品，不是缓存。自行构建的调试包使用本机调试签名；重新生成相同发布签名需要原私钥，不能从公开源码恢复。完整构建说明见 [BUILDING.md](BUILDING.md)。

飞机、场景、机器人和界面使用本项目的原创矢量绘制；三首循环音乐、七种音效由 `tools/synthesize_audio.py` 生成，没有使用任天堂或 FNAF 的角色、商标和素材。新增三首电台曲目从用户提供的 MP4 中提取，主界面也可打开电台。来源见 [音乐说明](docs/music-sources.md)，这些录音不属于项目原创素材。
